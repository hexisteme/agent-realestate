## v1 에서 찾은 문제 → 바꾼 규칙 (Codex 2라운드 REVISE·agy 2라운드 FAIL 반영)
1. 현재 국면 자기 매칭 → 후보는 현재 판정월보다 **48개월 이상 앞선 달**만(c − t ≥ 48). 48 = 결과 36개월 + 가격 흐름 창 12개월.
2. 대칭 투표가 가격 흐름 정반대 달을 닮았다고 함 → **A1 가격 흐름은 구간과 방향(+0.5% 초과 오름·−0.5% 미만 내림·그 사이 보합) 모두 같아야** 하고,
   나머지 5축 중 **4개 이상** 같아야 한다.
3. 판정 불가 축 섞임 → 후보·비교 기준 모두 **6축 전부 판정 가능한 달**만.
4. '닮은 달 전부' 집계가 겹친 달을 반복 집계 → 집계 삭제, 사례마다 묶인 달 목록만 남긴다.
5. 집계 게이트를 첫 문장에만 적용 → 모든 변형·지평에서 결과 확인 n < 5 이면 오름·내림 수·중위·사분위·빼고 세기를 내지 않고
   개별 사례·미도래·결측만 적는다.
6. 비교 기준은 사례와 같은 모집단(6축 판정 가능, c − t ≥ 간격, 결과 확인)으로 첫머리에 둔다. 월별 결과 창이 겹친다고 적고,
   대표월 집계와 우열 비교를 하지 않는다.
7. 결과가 없을 때: 끝 달이 마지막 가격 관측월보다 뒤면 미도래, 아니면 결측.
8. 결과 기준 문구: "규칙상 기준 관측월(판정월 직전 달)의 최신 개정 지수".
